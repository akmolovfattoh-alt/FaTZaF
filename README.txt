FaTZaF Messenger — Django

Возможности:
- регистрация и личные чаты;
- эмодзи в панели сообщения;
- создание групп минимум на 3 участника (создатель + минимум 2 выбранных);
- создание каналов, где писать могут администраторы;
- пересылка сообщений между чатами;
- отметка последнего посещения пользователя;
- редактирование и удаление собственных сообщений;
- светлая и тёмная тема.

Запуск в Windows:
1. Откройте терминал в папке, где лежит manage.py.
2. Создайте и активируйте виртуальное окружение:
   py -m venv venv
   venv\Scripts\activate
3. Установите зависимости:
   pip install -r requirements.txt
4. Примените миграции:
   python manage.py migrate
5. Создайте администратора (необязательно):
   python manage.py createsuperuser
6. Запустите:
   python manage.py runserver
7. Откройте http://127.0.0.1:8000/

Важно: «последний раз был(а)» обновляется при открытии страниц приложения. Для точного статуса онлайн в реальном времени потребуется периодический heartbeat или WebSocket. Это учебный прототип; перед публикацией в интернете настройте SECRET_KEY, DEBUG, ALLOWED_HOSTS и безопасность загрузок.
